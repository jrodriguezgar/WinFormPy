# Application Templates

WinFormPy includes ready-to-use application boilerplates demonstrating real-world usage patterns and modern UI styles.

## Available Templates

| Template | Description | File |
| --- | --- | --- |
| **Studio** | IDE-style (VS Code pattern) | [studio_template.py](studio_template.py) |
| **Explorer** | Windows 11 File Explorer | [explorer_template.py](explorer_template.py) |
| **Browser** | Modern Tabbed Browser | [browser_template.py](browser_template.py) |
| **WinUI 3 Gallery** | Interactive controls gallery | [winui3_template.py](winui3_template.py) |
| **Navigation Pane** | Hamburger menu layout | [navigation_pane_template.py](navigation_pane_template.py) |
| **Navigation Rail** | Slim vertical rail layout | [navigation_rail_template.py](navigation_rail_template.py) |
| **MAUI** | .NET MAUI Shell architecture | [maui_template.py](maui_template.py) |
| **MDI** | Classic Multiple Document Interface | [mdi_template.py](mdi_template.py) |

## How to use
Each template is a self-contained Python script. You can run them directly:
```bash
python winformpy/templates/explorer_template.py
```
Or inherit from them to build your custom application logic.
